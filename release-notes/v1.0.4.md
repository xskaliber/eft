# Xskaliber EFT 1.0.4

**Released:** YYYY-MM-DD
**Type:** Routine release
**Upgrading from:** 1.0.3

Job completion emails and configurable sign-in security.

## Before you upgrade

| # | Change | What to do |
|---|--------|------------|
| 1 | Values under **System Settings → Security Configuration** now take effect. Values nobody changed are reset to the current built-in policy, so nothing changes for most installations. If an administrator did change them, those values apply after the upgrade, kept within the new allowed ranges. | Review **Security Configuration** after upgrading (see [Sign-in security](../tutorials/09-system-settings.md#sign-in-security)). |

Upgrade with **Update stack → Replace existing template**, using the 1.0.4 deployment template from your Marketplace subscription. See [Upgrading](../README.md#-upgrading).

## After you upgrade

1. To get job completion emails, fill in **System Settings → SMTP/Email Configuration** and use **Send test email** to check it (see [Email](../tutorials/09-system-settings.md#email)).

## New

- **Job completion emails.** Partner jobs with **Send Completion Email** turned on email their recipients each time they succeed or fail, with the partner, files processed and any error. See [tutorial 7](../tutorials/07-partner-jobs.md).
- **Send test email** on the **SMTP/Email Configuration** tab checks the mail server settings and shows the server's reason if sending fails.
- **Configurable sign-in security.** **Min Password Length** (12 to 128), **Max Login Attempts** (3 to 10), **Lockout Duration** (5 to 1440 minutes) and **Session Lifetime** (1 to 168 hours) under **Security Configuration** now apply without a restart. Password forms show the current minimum length.

## Fixes

- Settings outside a setting's allowed range are now rejected when saved, and the edit dialog shows the allowed range.

## Removed

- The unused **JWT Secret** row under **Security Configuration**. The sign-in signing secret is generated for each installation in AWS Secrets Manager and was never read from this setting.

## Known issues

None at release.
