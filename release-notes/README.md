# Release notes

Published releases of Xskaliber EFT, newest first. Each page lists what changed and anything you need to do before or after upgrading.

| Version | Released | Type | Highlights |
|---------|----------|------|------------|
| [1.0.3](v1.0.3.md) | 2026-10-19 | Initial release | First general release on AWS Marketplace |

**Release types**

| Type | Meaning |
|------|---------|
| **Security** | Fixes security issues. Upgrade as soon as you can. |
| **Routine** | New features and fixes. Upgrade at your convenience. |

The console shows an **Update Available** banner when a newer version is published. To upgrade, see [Upgrading](../README.md#-upgrading). If you are more than one version behind, read the notes for every version in between.

To be told about security issues privately, or to report one, email [security@xskaliber.com](mailto:security@xskaliber.com).
